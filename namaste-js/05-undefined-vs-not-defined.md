## undefined

- in JS, when a variable is not assigned any value is of type undefined.
- it means varible is declared but value is not assigned to it.

- variable with undefined value has a memory.

ex :

let a ; 
console.log(a); // undefined

## not defined

- in JS, when you try to access a variable which is not declared yet in the code.

ex : 

let a = 20 ; 
console.log(b); // b is not defined.

- not defined is an error and variable for which we are getting not defined does not have a memory.
