## what is execution context

- Javascript Execution Context is the environment in which Javascript code is executed.
- Everything in Javascript happens inside an execution context

- Javascript Execution Context executes code in 2 phases
    1. Memory Phase ( Variable Environment )
    2. Execution Phase ( Thread of Execution )

- Javascript is synchoronous & single Threaded Language.

- Synchronous means it first completes the execution of current line and them it moves to the next line.
- Single Threaded means it executes all the task in single thread which is a main thread.
