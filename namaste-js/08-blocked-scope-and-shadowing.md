## Block

- In JavaScript, a block is a structure used to group one or more statements together. 
- Block is defined by {}.

## Blocked Scope

- variables and functions which we can access in a Block.

- illegal shadowing

ex: 

let a = 20 
{
    var a = 20 ; // illegal shadowing
}

## Shadowing

- a local variable has a same name as a variable which is in outer scope.
